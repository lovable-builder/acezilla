04

Seven bets that make it state of the art

1 · Modeled ROAS beside platform ROAS, everywhereEvery table shows what the platform claims next to what actually happened.
2 · Response-curve budgetingAllocate by marginal return rather than average ROAS. The planner shows where the next dollar should go.
3 · Platform translation layerWrite one brief and get valid native setups on all three platforms, with spec checks before submission.
4 · Second-by-second creative readHook, hold and drop-off points for each creative, explained in plain language, plus fatigue predicted before ROAS falls.
5 · Suggest-only AI with receiptsEvery suggestion shows its estimated impact, confidence and data sources. Applying one means creating a draft, never a silent change.
6 · Built-in incrementalityGeo-holdout and conversion-lift tests that recalibrate the attribution model automatically.
7 · Approvals as a first-class workflowBuyers, leads and clients approve from one queue, with an audit log, spend limits and role-based permissions. This is what makes suggest-only practical at agency scale.

06

Integrations & data

TikTokMarketing API (campaigns, reporting, creative), Events API. Developer app approval required.
MetaMarketing API + Conversions API. Requires App Review and Business Verification for ads_management.
GoogleGoogle Ads API (developer token, Standard access) plus GA4 Data API and Merchant Center.

Pipeline: OAuth connectors → incremental sync workers that respect each API's rate limits → warehouse with a normalized model (account → campaign → ad set/group → ad → creative) → store and server-side event reconciliation → modeling layer (data-driven attribution, MMM, response curves) → app and copilot. The copilot retrieves from the warehouse and cites every number it uses.
